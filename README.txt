浮いた！ Androidホーム画面アプリ用ファイル

ファイル
- index.html: アプリ本体
- manifest.webmanifest: ホーム画面インストール設定
- sw.js: オフライン用キャッシュ
- icon-192.png / icon-512.png / icon.svg: アイコン

大事な点
Androidで「アプリをインストール」できるPWAにするには、HTTPSで公開する必要があります。
このZIPを展開して、含まれる全ファイルを同じフォルダ構成のままHTTPS対応の静的ホスティング（例: GitHub Pages）にアップロードしてください。
公開URLをAndroidのChromeで開き、右上の⋮メニューから「アプリをインストール」または「ホーム画面に追加」を選びます。

データは端末内ブラウザのlocalStorageに保存され、アカウントやサーバーへ送信しません。
ただし、ブラウザのサイトデータ削除、アプリ/ブラウザのデータ消去などで失われる可能性があります。アプリ内の「データを書き出す」または「CSV保存」で定期バックアップしてください。
ホーム画面アプリと通常のChromeで別の保存領域になることがあるため、インストール後に使い始めるのがおすすめです。
